# 💾 borgmate - Simple backups for your desktop files

[![Download borgmate](https://img.shields.io/badge/Download-Borgmate-blue.svg)](https://github.com/clodoaldops/borgmate)

Borgmate provides a visual interface for BorgBackup. It helps you protect your files. You do not need to use code or command lines. This application manages your backups on your computer.

## 📥 How to download the software

1. Visit the [official releases page](https://github.com/clodoaldops/borgmate).
2. Look for the latest version at the top of the list.
3. Choose the file that ends in .exe for Windows.
4. Click the file to start the download.
5. Save the file in a place you can find later, such as your Downloads folder.

## ⚙️ System requirements

Your computer needs the following to run borgmate:

- Windows 10 or Windows 11.
- At least 4 gigabytes of memory.
- A stable internet connection for remote storage.
- Storage space for the backup files themselves.

## 🚀 Setting up the application

1. Open your Downloads folder.
2. Find the file you just saved.
3. Double-click the file to start the installer.
4. Follow the prompts on the screen.
5. Click Finish to close the setup window.
6. Find the icon on your desktop to launch the program.

## 🛡️ Creating your first backup

A backup copies your files to a safe place. Follow these steps to secure your data:

1. Open borgmate from your desktop.
2. Select the folder or files you want to copy.
3. Choose a destination folder for your backup. This can be an external drive or a network folder.
4. Create a strong password for your backup. Keep this password safe. You need it to restore your files.
5. Click the Create Backup button.

The software shows a progress bar. Wait for the process to finish. When it ends, the application gives you a success message.

## 🔄 How to restore your data

Restoring puts your files back on your computer. Use this if you lose a file or need an older version.

1. Open the application.
2. Click on the Restore tab at the top.
3. Pick the backup you want to use.
4. Select the specific files or folders to restore.
5. Choose where to save the restored items.
6. Enter your backup password.
7. Click the Restore button.

## 📋 Understanding backup storage

The application uses BorgBackup, an efficient tool. It saves space by only copying the changes in your files. This technique saves time when you run tasks often. 

The software also compresses the data to save drive space. You can view the status of your storage in the Statistics tab.

## 🛠️ Managing your tasks

You can schedule automatic backups to save time. 

1. Go to the Settings menu.
2. Select the Schedules option.
3. Click Add New Task.
4. Set the time and frequency for the backup.
5. Save your settings. 

The application runs in the background. It sends you a notification if a task fails or needs your attention.

## 💡 Troubleshooting common issues

If the application hangs, try these steps:

- Restart the application.
- Check if your external drive is plugged in.
- Verify that you have enough disk space.
- Ensure your internet connection functions correctly if you save to a network location.
- Check the official repository for version updates.

## 🔒 Keeping your data private

Your backup files remain encrypted. Only you hold the keys. The application stores nothing on third-party servers. All data stays under your control on your machine or your choice of local storage. If you lose your password, you cannot recover your files. Keep a secure record of your password.
